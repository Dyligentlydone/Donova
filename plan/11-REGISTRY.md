# 11 — Registry (`registry/` + `@donova/registry-client`)

A catalog of reusable, editable source — not a black-box plugin system. Installing an item
copies HTML/CSS/JS into the user's project where they (or the agent) can edit it.

## 1. Item types
| Type | Installs to | Wiring |
|---|---|---|
| `block` | `compositions/<name>.html` (sub-composition) | host `<div data-composition-id data-composition-src data-start data-duration data-track-index data-variable-values>` inserted into target composition |
| `component` | `compositions/components/<name>.html` snippet (HTML + scoped CSS + GSAP function) | merged into a target composition: markup appended into a container, CSS into `<style>`, JS registered as a function `window.__fcComponents["name"](tl, root, opts)` called from the composition script |
| `motion-preset` | (no files) JSON snippet for `data-fc-motion` with `{{duration}}`/`{{distance}}` params | applied by Studio inspector / agent to one element; GSAP-free |
| `caption-style` | `compositions/captions/<name>.html` | used by captions generator |
| `transition` | component subtype: function `(tl, outgoing, incoming, at, duration)` | inserted at a scene seam |
| `example` | project template | `donova init --template` |
| `look` | `assets/luts/<name>.cube` + preset JSON | color grade preset |
| `sfx` | `assets/sfx/<name>.wav` | `<audio>` element |

## 3. Client (`registry-client`)
- `fetchIndex(url)` with ETag caching to `~/.cache/donova/registry/`; offline uses cache.
- `search(query, {type, tags})`: fuzzy over name/title/description/tags (minisearch), boost tag matches.
- `install(name, project, {into, at, force})`:
  1. Download item json + files (verify sha256).
  2. Resolve dependencies (items first, recursive; cycle guard).
  3. Rewrite composition id if it collides; scope CSS (`[data-composition-id="<id>"]` prefix) if not scoped.
  4. Localize fonts (04 §3.3) into `assets/__fonts/`.
  5. Write files (refuse to overwrite modified files without `--force`; track in `donova.json` `"installed": {name: {version, sha256}}`).
  6. If `into`: insert host element into the target composition at time `at` (default: playhead/0) on a free track; append `data-variable-values` with defaults.
  7. Run lint on changed files; report.
- `remove(name)`: delete files + host elements (confirm if modified).

## 4. Authoring and CI for registry items
- Each item folder: `<name>.html`, `registry-item.json`, `README.md` (what/when/variables), `preview.mp4` (rendered by CI), `poster.jpg`.
- `pnpm registry:validate`: schema validation, lint (0 errors), `check` (0 errors), render each declared aspect, variables smoke test (render with min/max-length strings), license present.
- `pnpm registry:build`: regenerate `registry.json`, render previews, upload to CDN (`registry.donova.dev`).
- Contribution flow: `donova registry new <name> --type block` scaffolds the folder.

## 6. Acceptance criteria
- `donova add lower-third-clean --into index.html --at 2` → host inserted, check passes, render shows it at 2 s.
- Installing the same block twice gets unique ids and both render.
- Offline install from cache works; tampered file (sha mismatch) is rejected.
- All catalog items pass `registry:validate` in CI.
